3 📚 Fundamentação Teórica

A manipulação de dados em Base R é sustentada por dois pilares principais: as estruturas de dados (que organizam as informações) e as funções (que operam sobre essas estruturas). Vetores e data frames são as estruturas mais utilizadas em análises práticas, e o R oferece um conjunto rico de funções nativas para manipulá-los sem dependência de pacotes externos (Batista e Oliveira, 2022).

A família apply representa uma alternativa mais eficiente e idiomática aos laços for, aplicando funções sobre linhas, colunas ou grupos de dados de forma concisa. Já as funções with(), within(), by(), ave(), aggregate() e split() ampliam essas capacidades para operações por grupo, criação de variáveis e resumo estatístico.

5.1 Vetores

O vetor é a estrutura de dados mais básica do R — todos os elementos devem ser do mesmo tipo. A aula apresentou criação, nomeação e operações sobre vetores, incluindo três formas de indexação.

Funções utilizadas: c(), names(), mean()

notas  <- c(7.5, 8.0, 6.5, 9.0, 5.5)
alunos <- c("Ana", "Bruno", "Carlos", "Daniela", "Eduardo")

# Nomeando elementos
names(notas) <- alunos

Código 
# Indexação por nome

Código 
# Indexação lógica
aprovados <- notas >= 7
notas[aprovados]   # aprovados

DicaDestaque

A indexação lógica é especialmente poderosa: ao passar um vetor de TRUE/FALSE, o R retorna apenas os elementos correspondentes a TRUE, sem necessidade de laços.

5.3 subset() — Subconjuntos de Data Frames

Filtra linhas de um data frame com base em condições lógicas, podendo também selecionar colunas específicas. É uma alternativa mais legível à indexação direta com [.

Sintaxe: subset(x, subset, select)

Código 
# Alunos com nota >= 7 em matemática
subset(dados, matematica >= 7)
    aluno matematica estatistica programacao
1     Ana        7.5         8.0         7.0
2   Bruno        8.0         7.5         8.5
4 Daniela        9.0         9.5         9.0
Código 
# Selecionando colunas específicas
subset(dados, select = c(aluno, programacao))
    aluno programacao
1     Ana         7.0
2   Bruno         8.5
3  Carlos         7.0
4 Daniela         9.0
5 Eduardo         5.0
Código 
# Condição múltipla
subset(dados, matematica >= 7 & estatistica >= 7)

5.4 Família apply

A família apply aplica uma função sobre elementos de uma estrutura de dados, evitando laços explícitos e tornando o código mais conciso e eficiente.

5.4.1 apply() — Aplicar sobre linhas ou colunas de matrizes/data frames

Aplica uma função sobre as linhas (MARGIN = 1) ou colunas (MARGIN = 2) de uma matriz ou data frame numérico.

Sintaxe: apply(X, MARGIN, FUN)

Código 
# Média por linha (por aluno)
apply(dados[, 2:4], 1, mean)
[1] 7.500000 8.000000 6.500000 9.166667 5.500000
Código 
# Média por coluna (por disciplina)
apply(dados[, 2:4], 2, mean)
 matematica estatistica programacao 
        7.3         7.4         7.3

5.4.2 lapply() — Aplicar sobre listas, retornar lista

Aplica uma função a cada elemento de uma lista ou vetor e sempre retorna uma lista.

Sintaxe: lapply(X, FUN)

Código 
lista_notas <- dados[, 2:4]

# Retorna lista
lapply(lista_notas, mean)
$matematica
[1] 7.3

$estatistica
[1] 7.4

$programacao
[1] 7.3

5.4.3 sapply() — Aplicar sobre listas, simplificar resultado

Funciona como lapply(), mas tenta simplificar o resultado — retornando um vetor ou matriz quando possível.

Sintaxe: sapply(X, FUN)

Código 
# Retorna vetor nomeado
sapply(lista_notas, mean)
 matematica estatistica programacao 
        7.3         7.4         7.3
DicaDiferença entre lapply e sapply

lapply() sempre retorna uma lista; sapply() simplifica o resultado para vetor ou matriz quando possível. Para resultados de comprimento uniforme, sapply() é geralmente mais conveniente.

5.4.4 tapply() — Aplicar por grupos

Aplica uma função a subconjuntos de um vetor, definidos por um fator de agrupamento. Retorna um array com os resultados por grupo.

Sintaxe: tapply(X, INDEX, FUN)

Código 
# Carregando penguins
library(palmerpenguins)
dados_limpos <- na.omit(penguins)

# Média do comprimento do bico por espécie
tapply(dados_limpos$bill_length_mm,
       dados_limpos$species,
       mean)

 38.82397  48.83382  47.56807
Código 
# Massa média por sexo
tapply(dados_limpos$body_mass_g,
       dados_limpos$sex,
       mean)
  female     male 
3862.273 4545.685

5.5 with() — Avaliar expressões no contexto de um data frame

Permite referenciar colunas de um data frame diretamente pelo nome, sem repetir df$ a cada vez. Não modifica o data frame original.

Sintaxe: with(data, expr)

Código 
# Sem with: necessário repetir o prefixo
mean(dados_limpos$body_mass_g)
[1] 4207.057
Código 
# Com with: mais legível
with(dados_limpos, mean(body_mass_g))
[1] 4207.057
Código 
# Combinando with e tapply
with(dados_limpos,
     tapply(body_mass_g, species, mean))
   Adelie Chinstrap    Gentoo 
 3706.164  3733.088  5092.437

5.6 within() — Modificar variáveis dentro de um data frame

Semelhante ao with(), mas permite criar, modificar ou remover variáveis dentro do data frame, retornando uma cópia modificada.

Sintaxe: within(data, expr)

Código 
df <- data.frame(a = 1:6,
                 b = rep(letters[1:3], each = 2))

# Criando nova variável de forma organizada
df2 <- within(df, {
  nova <- a * 2
})
df2
  a b nova
1 1 a    2
2 2 a    4
3 3 b    6
4 4 b    8
5 5 c   10
6 6 c   12
Dicawith() vs within()

with() avalia uma expressão no contexto do data frame sem modificá-lo. within() permite criar ou modificar variáveis e retorna o data frame atualizado.

5.7 by() — Aplicar função por grupos (versão generalizada)

Aplica uma função a subgrupos de um data frame. É mais geral do que tapply() pois aceita múltiplas variáveis de agrupamento e opera sobre data frames inteiros (não apenas vetores).

5.8 ave() — Estatística por grupo no mesmo tamanho do vetor

Calcula uma estatística por grupo e retorna um vetor do mesmo comprimento do vetor original, com o resultado repetido para cada observação do grupo. Útil para comparar cada indivíduo com a média do seu grupo.

Sintaxe: ave(x, ..., FUN = mean)

Código 
df <- data.frame(a = 1:6,
                 b = rep(letters[1:3], each = 2))

# Média de 'a' por grupo 'b', repetida para cada linha
ave(df$a, df$b, FUN = mean)
[1] 1.5 1.5 3.5 3.5 5.5 5.5
Código 
# Aplicação prática: comparar cada pinguim com a média da espécie
dados_limpos$media_por_especie <- ave(dados_limpos$body_mass_g,
                                      dados_limpos$species,
                                      FUN = mean)

# Identificar quem está acima da média da própria espécie
dados_limpos$acima_media <- dados_limpos$body_mass_g >
  dados_limpos$media_por_especie

table(dados_limpos$acima_media)

FALSE  TRUE 
  175   158

5.9 aggregate() — Resumir dados por grupo em data frame

Agrega dados calculando uma estatística por grupo e retorna um data frame com os resultados. Suporta fórmulas (y ~ x) para especificar variável e agrupamento.

Sintaxe: aggregate(x ~ group, data, FUN)

Código 
# Média de uma variável por espécie
aggregate(body_mass_g ~ species,
          data = dados_limpos,
          FUN = mean)
    species body_mass_g
1    Adelie    3706.164
2 Chinstrap    3733.088
3    Gentoo    5092.437
Código 
# Média por espécie e sexo
aggregate(body_mass_g ~ species + sex,
          data = dados_limpos,
          FUN = mean)

2 Chinstrap female    3527.206
3    Gentoo female    4679.741
4    Adelie   male    4043.493
5 Chinstrap   male    3938.971
6    Gentoo   male    5484.836
Código 
# Múltiplas variáveis simultaneamente
aggregate(cbind(bill_length_mm, flipper_length_mm, body_mass_g) ~ species,
          data = dados_limpos,
          FUN = mean)

5.10 split() — Dividir data frame em lista por grupos

Divide um data frame (ou vetor) em uma lista de subconjuntos, um por nível do fator de agrupamento. Frequentemente combinado com lapply() ou sapply().

Sintaxe: split(x, f)

Código

dados_split <- split(dados_limpos, dados_limpos$species)

# Nomes dos grupos
names(dados_split)

5.11 Estruturas de Controle

As estruturas de controle direcionam o fluxo de execução do programa. A aula apresentou if/else, for e while, comparando-os com as abordagens vetorizadas da família apply.

5.11.1 if / else

Executa um bloco de código condicionalmente.

Código 
nota_media_ana <- dados$media[1] <- mean(c(7.5, 8.0, 7.0))

if (nota_media_ana >= 7) {
  print("Ana está aprovada")
} else {
  print("Ana está reprovada")
}
[1] "Ana está aprovada"

5.11.2 for — Laço com iteração explícita

Repete um bloco para cada elemento de um vetor ou lista. A aula demonstrou que apply é preferível ao for em muitos casos práticos.

Código 
# Classificando alunos com for + if (forma explícita)
situacao_manual <- character(nrow(dados))

for (i in 1:nrow(dados)) {
  if (dados$media[i] >= 7) {
    situacao_manual[i] <- "Aprovado"
  } else {
    situacao_manual[i] <- "Reprovado"
  }
}

situacao_manual
[1] "Aprovado" "Aprovado" "Aprovado" "Aprovado" "Aprovado"
Código 
# Equivalente vetorizado com ifelse (preferível)
ifelse(dados$media >= 7, "Aprovado", "Reprovado")
[1] "Aprovado" "Aprovado" "Aprovado" "Aprovado" "Aprovado"

5.11.3 while — Laço com condição de parada

Repete um bloco enquanto uma condição for verdadeira.

Código 
# Simulando crescimento até atingir valor alvo
media_simulada <- 5.0
incremento     <- 0.3
iteracoes      <- 0

while (media_simulada < 7) {
  media_simulada <- media_simulada + incremento
  iteracoes      <- iteracoes + 1
}

cat("Média final:", round(media_simulada, 2), "\n")
Média final: 7.1
Código 
cat("Iterações necessárias:", iteracoes, "\n")
Iterações necessárias: 7

5.11.4 Comparação: for vs apply vs sapply

A aula destacou que, para operações sobre colunas de data frames, apply e sapply são mais concisos e geralmente mais eficientes do que laços for explícitos.

Código 
# Usando for
medias_for <- numeric(ncol(dados[, 2:4]))
for (i in 1:ncol(dados[, 2:4])) {
  medias_for[i] <- mean(dados[, 2:4][, i])
}
medias_for
[1] 7.3 7.4 7.3
Código 
# Usando apply
apply(dados[, 2:4], 2, mean)
 matematica estatistica programacao 
        7.3         7.4         7.3
Código 
# Usando sapply
sapply(dados[, 2:4], mean)
 matematica estatistica programacao 
        7.3         7.4         7.3

7 🧠 Considerações Finais

A Aula 04 demonstrou que o Base R oferece um conjunto rico e expressivo de ferramentas para manipulação de dados, dispensando pacotes externos para a maioria das tarefas analíticas cotidianas.

Os principais aprendizados foram:

  • A família apply (apply, lapply, sapply, tapply) permite substituir laços explícitos por código mais conciso e idiomático
  • As funções with() e within() melhoram a legibilidade do código ao evitar a repetição do nome do data frame
  • by(), tapply() e aggregate() são complementares: tapply retorna arrays, by é mais geral para agrupamentos complexos, e aggregate retorna data frames prontos para uso
  • ave() é especialmente útil para comparar cada observação com a estatística do seu próprio grupo, mantendo o vetor no mesmo tamanho dos dados originais
  • split() combinado com lapply() oferece uma abordagem flexível para operações por grupo
  • As estruturas de controle (if, for, while) são fundamentais, mas a aula evidenciou que abordagens vetorizadas são preferíveis sempre que possível, por serem mais concisas e eficientes

## 🔍 Funções Apresentadas na Aula

### Vetores

O vetor é a estrutura de dados mais básica do R — todos os elementos devem ser do mesmo tipo. A aula apresentou criação, nomeação e operações sobre vetores, incluindo três formas de indexação.

**Funções utilizadas:** `c()`, `names()`, `mean()`

```{r}
# Criando vetores
notas  <- c(7.5, 8.0, 6.5, 9.0, 5.5)
alunos <- c("Ana", "Bruno", "Carlos", "Daniela", "Eduardo")

# Nomeando elementos
names(notas) <- alunos
notas

# Operação vetorial
media <- mean(notas)
media

# Indexação posicional
notas[1]

# Indexação por nome
notas["Ana"]

# Indexação lógica
aprovados <- notas >= 7
notas[aprovados]   # aprovados
notas[!aprovados]  # reprovados
```

::: {.callout-tip title="Destaque"}
A indexação lógica é especialmente poderosa: ao passar um vetor de `TRUE`/`FALSE`, o R retorna apenas os elementos correspondentes a `TRUE`, sem necessidade de laços.
:::

### Data Frame

O data frame é uma estrutura tabular onde cada coluna pode ter um tipo diferente. É criado com `data.frame()` e inspecionado com `str()` e `summary()`.

**Funções utilizadas:** `data.frame()`, `str()`, `summary()`

```{r}
dados <- data.frame(
  aluno       = alunos,
  matematica  = c(7.5, 8.0, 6.5, 9.0, 5.5),
  estatistica = c(8.0, 7.5, 6.0, 9.5, 6.0),
  programacao = c(7.0, 8.5, 7.0, 9.0, 5.0)
)

dados
str(dados)
summary(dados)

# Acessando colunas
dados$matematica
dados[, "estatistica"]
dados[, 2]
```

### `subset()` — Subconjuntos de Data Frames

Filtra linhas de um data frame com base em condições lógicas, podendo também selecionar colunas específicas. É uma alternativa mais legível à indexação direta com `[`.

**Sintaxe:** `subset(x, subset, select)`

```{r}
# Alunos com nota >= 7 em matemática
subset(dados, matematica >= 7)

# Selecionando colunas específicas
subset(dados, select = c(aluno, programacao))

# Condição múltipla
subset(dados, matematica >= 7 & estatistica >= 7)
```

### Família `apply`

A família `apply` aplica uma função sobre elementos de uma estrutura de dados, evitando laços explícitos e tornando o código mais conciso e eficiente.

#### `apply()` — Aplicar sobre linhas ou colunas de matrizes/data frames

Aplica uma função sobre as linhas (`MARGIN = 1`) ou colunas (`MARGIN = 2`) de uma matriz ou data frame numérico.

**Sintaxe:** `apply(X, MARGIN, FUN)`

```{r}
# Média por linha (por aluno)
apply(dados[, 2:4], 1, mean)

# Média por coluna (por disciplina)
apply(dados[, 2:4], 2, mean)
```

---

#### `lapply()` — Aplicar sobre listas, retornar lista

Aplica uma função a cada elemento de uma lista ou vetor e **sempre retorna uma lista**.

**Sintaxe:** `lapply(X, FUN)`

```{r}
lista_notas <- dados[, 2:4]

# Retorna lista
lapply(lista_notas, mean)
```

---

#### `sapply()` — Aplicar sobre listas, simplificar resultado

Funciona como `lapply()`, mas tenta **simplificar** o resultado — retornando um vetor ou matriz quando possível.

**Sintaxe:** `sapply(X, FUN)`

```{r}
# Retorna vetor nomeado
sapply(lista_notas, mean)
```

::: {.callout-tip title="Diferença entre lapply e sapply"}
`lapply()` sempre retorna uma lista; `sapply()` simplifica o resultado para vetor ou matriz quando possível. Para resultados de comprimento uniforme, `sapply()` é geralmente mais conveniente.
:::

---

#### `tapply()` — Aplicar por grupos

Aplica uma função a subconjuntos de um vetor, definidos por um fator de agrupamento. Retorna um array com os resultados por grupo.

**Sintaxe:** `tapply(X, INDEX, FUN)`

```{r}
# Carregando penguins
library(palmerpenguins)
dados_limpos <- na.omit(penguins)

# Média do comprimento do bico por espécie
tapply(dados_limpos$bill_length_mm,
       dados_limpos$species,
       mean)

# Massa média por sexo
tapply(dados_limpos$body_mass_g,
       dados_limpos$sex,
       mean)
```

---

### `with()` — Avaliar expressões no contexto de um data frame

Permite referenciar colunas de um data frame diretamente pelo nome, sem repetir `df$` a cada vez. Não modifica o data frame original.

**Sintaxe:** `with(data, expr)`

```{r}
# Sem with: necessário repetir o prefixo
mean(dados_limpos$body_mass_g)

# Com with: mais legível
with(dados_limpos, mean(body_mass_g))

# Combinando with e tapply
with(dados_limpos,
     tapply(body_mass_g, species, mean))
```

---

### `within()` — Modificar variáveis dentro de um data frame

Semelhante ao `with()`, mas permite **criar, modificar ou remover variáveis** dentro do data frame, retornando uma cópia modificada.

**Sintaxe:** `within(data, expr)`

```{r}
df <- data.frame(a = 1:6,
                 b = rep(letters[1:3], each = 2))

# Criando nova variável de forma organizada
df2 <- within(df, {
  nova <- a * 2
})
df2
```

::: {.callout-tip title="with() vs within()"}
`with()` avalia uma expressão no contexto do data frame sem modificá-lo. `within()` permite criar ou modificar variáveis e retorna o data frame atualizado.
:::

---

### `by()` — Aplicar função por grupos (versão generalizada)

Aplica uma função a subgrupos de um data frame. É mais geral do que `tapply()` pois aceita múltiplas variáveis de agrupamento e opera sobre data frames inteiros (não apenas vetores).

**Sintaxe:** `by(data, INDICES, FUN)`

```{r}
# Média da massa por espécie
by(dados_limpos$body_mass_g,
   dados_limpos$species,
   mean)

# Agrupamento por espécie e sexo
by(dados_limpos$body_mass_g,
   dados_limpos[, c("species", "sex")],
   mean)
```

::: {.callout-tip title="by() vs tapply()"}
Ambas aplicam funções por grupo, mas `by()` aceita data frames inteiros como primeiro argumento e lida melhor com agrupamentos múltiplos complexos. `tapply()` opera sobre vetores e retorna arrays, sendo mais adequado para agrupamentos simples.
:::

---

### `ave()` — Estatística por grupo no mesmo tamanho do vetor

Calcula uma estatística por grupo e **retorna um vetor do mesmo comprimento** do vetor original, com o resultado repetido para cada observação do grupo. Útil para comparar cada indivíduo com a média do seu grupo.

**Sintaxe:** `ave(x, ..., FUN = mean)`

```{r}
df <- data.frame(a = 1:6,
                 b = rep(letters[1:3], each = 2))

# Média de 'a' por grupo 'b', repetida para cada linha
ave(df$a, df$b, FUN = mean)

# Aplicação prática: comparar cada pinguim com a média da espécie
dados_limpos$media_por_especie <- ave(dados_limpos$body_mass_g,
                                      dados_limpos$species,
                                      FUN = mean)

# Identificar quem está acima da média da própria espécie
dados_limpos$acima_media <- dados_limpos$body_mass_g >
  dados_limpos$media_por_especie

table(dados_limpos$acima_media)
```

---

### `aggregate()` — Resumir dados por grupo em data frame

Agrega dados calculando uma estatística por grupo e retorna um **data frame** com os resultados. Suporta fórmulas (`y ~ x`) para especificar variável e agrupamento.

**Sintaxe:** `aggregate(x ~ group, data, FUN)`

```{r}
# Média de uma variável por espécie
aggregate(body_mass_g ~ species,
          data = dados_limpos,
          FUN = mean)

# Média por espécie e sexo
aggregate(body_mass_g ~ species + sex,
          data = dados_limpos,
          FUN = mean)

# Múltiplas variáveis simultaneamente
aggregate(cbind(bill_length_mm, flipper_length_mm, body_mass_g) ~ species,
          data = dados_limpos,
          FUN = mean)
```

---

### `split()` — Dividir data frame em lista por grupos

Divide um data frame (ou vetor) em uma **lista de subconjuntos**, um por nível do fator de agrupamento. Frequentemente combinado com `lapply()` ou `sapply()`.

**Sintaxe:** `split(x, f)`

```{r}
# Dividindo por espécie
dados_split <- split(dados_limpos, dados_limpos$species)

# Nomes dos grupos
names(dados_split)

# Média da massa em cada grupo
lapply(dados_split, function(df) mean(df$body_mass_g))

# Número de observações por grupo
sapply(dados_split, nrow)
```

### Estruturas de Controle

As estruturas de controle direcionam o fluxo de execução do programa. A aula apresentou `if/else`, `for` e `while`, comparando-os com as abordagens vetorizadas da família `apply`.

#### `if` / `else`

Executa um bloco de código condicionalmente.

```{r}
nota_media_ana <- dados$media[1] <- mean(c(7.5, 8.0, 7.0))

if (nota_media_ana >= 7) {
  print("Ana está aprovada")
} else {
  print("Ana está reprovada")
}
```

---

#### `for` — Laço com iteração explícita

Repete um bloco para cada elemento de um vetor ou lista. A aula demonstrou que `apply` é preferível ao `for` em muitos casos práticos.

```{r}
# Classificando alunos com for + if (forma explícita)
situacao_manual <- character(nrow(dados))

for (i in 1:nrow(dados)) {
  if (dados$media[i] >= 7) {
    situacao_manual[i] <- "Aprovado"
  } else {
    situacao_manual[i] <- "Reprovado"
  }
}

situacao_manual

# Equivalente vetorizado com ifelse (preferível)
ifelse(dados$media >= 7, "Aprovado", "Reprovado")
```

---

#### `while` — Laço com condição de parada

Repete um bloco enquanto uma condição for verdadeira.

```{r}
# Simulando crescimento até atingir valor alvo
media_simulada <- 5.0
incremento     <- 0.3
iteracoes      <- 0

while (media_simulada < 7) {
  media_simulada <- media_simulada + incremento
  iteracoes      <- iteracoes + 1
}

cat("Média final:", round(media_simulada, 2), "\n")
cat("Iterações necessárias:", iteracoes, "\n")
```

---

#### Comparação: `for` vs `apply` vs `sapply`

A aula destacou que, para operações sobre colunas de data frames, `apply` e `sapply` são mais concisos e geralmente mais eficientes do que laços `for` explícitos.

```{r}
# Usando for
medias_for <- numeric(ncol(dados[, 2:4]))
for (i in 1:ncol(dados[, 2:4])) {
  medias_for[i] <- mean(dados[, 2:4][, i])
}
medias_for

# Usando apply
apply(dados[, 2:4], 2, mean)

# Usando sapply
sapply(dados[, 2:4], mean)
```
